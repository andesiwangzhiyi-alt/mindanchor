# 开源项目源码分析

对「锚」开发过程中研究的 4 个相关开源项目源码分析。源码下载脚本见 `research/dl_ocd_repos*.py`（Playwright 驱动 Chrome 绕过直连封锁）。

## 1. krishna — OCD 知情 CBT/ERP 聊天机器人（Python CLI）

**架构**：极简状态机对话系统，`SessionState` dataclass 管理：

```
INTAKE（2 轮，了解最近情境）→ GOAL（1-2 周小目标）→ WORK（生成 ERP 微实验）→ WRAP（总结）
```

**核心亮点**：
- **vignette 场景库 JSON**（`app/vignettes/ocd_core.JSON`）四层结构：`keywords`（关键词匹配）/ `scenario`（情境模板）/ `targets`（该做什么）/ `avoid`（绝不做什么）
  - avoid 示例：不诊断、不保证安全（"you are fine"）、不鼓励强迫行为、不陷入安慰循环
- **ERP 微实验按主题预设**：污染→"延迟洗手 30 秒"；检查→"只查一次就离开"；侵入性思维→"给念头贴标签"
- 每个实验引导观察**焦虑的上升-平台-下降**（ERP 习惯化核心）

**局限**：LLM 为 mock（真实模型未接通）、CLI 交互门槛高、无 UI 无记录。**本质是优秀的提示词工程骨架。**

**对「锚」的贡献**：AI 引导的系统提示词原则 + 主题化微实验建议（v0.1 实现）。

## 2. OCDetour — 延迟强迫行为 App（React 全栈）

**架构**：React + GraphQL + JWT 登录 + 后端。用户自定义"活动"（延迟任务）。

**核心机制**（整个 App 只做一件事）：
```
活动卡片（如"延迟检查门锁 5 分钟"）→ 点击 → 呼吸动画 + 倒计时 → "You did it!" 完成反馈
```

**亮点**：交互极简；`react-countdown` 倒计时 + `BreatheIcon` 呼吸动画陪伴；完成有正反馈。"延迟"动作被设计得毫无负担。

**局限**：功能单一、必须登录 + 部署后端、无追踪。

**对「锚」的贡献**："延迟强迫"概念 → 念头停车场 + 担忧时间预约（v0.0.1 实现）。

## 3. ocd-practice — OCD 日常练习 + ERP 追踪（单文件 HTML）

**四个项目里最值得借鉴的一个。**

| 模块 | 机制 | 亮点 |
|---|---|---|
| Incident 记录 | 情境 + **SUDS 0-100 滑杆** + 仪式描述 + 分钟数 | 标准临床量表 |
| 5 分钟冥想 | 5×60s：安顿 → 念头贴标签 → 允许焦虑 → 观察冲动 → 夺回主权 | 脚本质量极高，每阶段一个具体动作 |
| Urge surfing | 冲动 0-10 评分 → 3 分钟观察 → 再评分 | "冲动自然下降"实证 |
| Exposure ladder | 5 级暴露任务逐级挑战 | 具体可执行 |
| Progress | Chart.js 7 天趋势 | 数据可视化 |

**金句设计**：
- "Thoughts are not commands. Urges are not emergencies."（念头不是命令，冲动不是紧急情况）
- "Logging is not a compulsion. It's data."（记录不是强迫，是数据）——防记录变成新强迫
- "Meditation is practice. ERP is treatment. Life is exposure."

**局限**：数据存 **Google Sheets**（国内不可访问）、全英文、依赖 CDN（Chart.js/Google Fonts）。

**对「锚」的贡献**：冥想脚本中文化 + SUDS 量表 + 暴露阶梯 + 冲动观察 + 金句（v0.1 全部落地）。

## 4. ERPMate — ERP 会话记录（Python 桌面）

**核心价值一个点**：记录 ERP 暴露后的**焦虑时间曲线**——暴露时 / 5 分钟 / 10 分钟 / 30 分钟 / 1 小时。

这是 ERP 习惯化的**核心证据**：证明"焦虑不动它也会自己降下来"。其余实现（PySimpleGUI + Excel）很简陋。

**对「锚」的贡献**：焦虑证据回访——记录 30 分钟后二次评分对比（v0.1 实现，简化为 2 点对比以降低使用负担）。

## 设计原则沉淀

1. **记录不是强迫**：所有记录保持极简、可选（"Logging is not a compulsion. It's data."）
2. **避免安抚循环**：不保证"你没事"，而是"观察它、允许它"（krishna avoid 列表）
3. **焦虑是成功不是失败**：ERP 中暴露后的焦虑出现=练习生效
4. **本地优先**：Google Sheets/CDN 依赖在国内不可用，全部本地化是「锚」的竞争优势
