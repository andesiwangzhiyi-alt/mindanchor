# 设计方案：锚 MindAnchor

本文档说明「锚」的设计原理、技术选型与各模块的临床依据。

## 一、问题定义

**目标用户**：有强迫思维（obsessive thinking / rumination）困扰、压力大时易发作的人群。

**核心痛点**：发作时陷入"越想越焦虑、越焦虑越想"的回路，需要一种**快速、低门槛、可重复**的打断机制。传统 CBT/ERP 需要治疗师在场；市面上商业 App 偏"日常训练"或"治疗师对接"，缺少**开源、中文、发作即用**的应急工具。

**设计原则**：
1. **速度优先**：一次点击、0 秒延迟、全屏接管
2. **多通道中断**：视觉 + 听觉（语音）+ 触觉（震动）
3. **不压抑、只寄存**：工具不"消灭"念头（压抑会反弹），而是延后处理
4. **绝不成为压力源**：每步可跳过、可退出；记录可选、极简
5. **数据主权**：全部本地存储，无云端

## 二、紧急协议的临床依据

### 阶段 1：中断（8 秒）
强迫回路需要强外部刺激打断。全屏红色 + 震动 + "停"指令，属于**刺激中断 / 注意力强制转移**技术。持续时间刻意很短（8 秒），避免制造新的恐惧。

### 阶段 2：生理性叹息呼吸（6 轮）
**生理性叹息（Physiological Sigh）**：双短吸（鼻）+ 长呼（嘴），由斯坦福大学 Huberman 实验室推广，是有文献支持的快速降压呼吸法（激活副交感神经、降低心率）。比普通深呼吸对 CO₂/心率变异性影响更明确。

### 阶段 3：5-4-3-2-1 感官着陆
经典**接地技术（Grounding）**，在焦虑/解离/恐慌中广泛应用：说出看到的 5 样东西、听到的 4 种声音、摸到的 3 种触感、闻到的 2 种气味、尝到的 1 种味道。作用是把注意力从内部思维硬锚回外部现实。

### 阶段 4：念头停车场 + 担忧时间
基于**担忧推迟技术（Worry Postponement）**：不压抑念头（压抑→反弹），而是"写下来、预约时间再想"。到点后的专门时段反而会削弱念头的强迫性。这与 **OCDetour**（延迟强迫）和 **ocd-practice** 的机制同源。

### 阶段 4 附加：冲动观察（Urge Surfing）
**冲动冲浪**：以 0-10 评分 + 3 分钟观察，体验"冲动像海浪一样升起、到达峰值、自然下降"。ERP 的核心实证：**冲动不动它也会自己消退**。

## 三、自我观察模块

### SUDS 0-100
主观痛苦单位（Subjective Units of Distress），CBT/ERP 的标准临床测量。四档标签（≤25 轻度 / ≤50 中度 / ≤75 高度 / >75 极度）便于快速理解。

### 焦虑证据回访
ERP 习惯化（habituation）理论的个人化应用：记录峰值 → 30 分钟后复评 → 对比显示"下降了 X 点"。**用个人数据打败"这次不一样"的念头**，是认知重构的实证路径。

### 7 天趋势
低门槛的模式发现：何时发作多、平均强度趋势。纯 canvas 绘制避免外部依赖（离线优先）。

## 四、每日微训练（预防侧）

借鉴 ocd-practice 的 5 分钟冥想脚本 + ACT 认知解离：

| 阶段 | 技术 | 目的 |
|---|---|---|
| 安顿 | 正念呼吸 | 建立观察者视角 |
| 念头贴标签 | 认知解离（"强迫念头"） | 与念头拉开距离 |
| 允许焦虑 | 接纳（"焦虑是被允许的"） | 停止与焦虑对抗 |
| 观察冲动 | 冲动评分 + 观察 | ERP 冲浪练习 |
| 夺回主权 | 自我声明 | 巩固行为自主感 |

设计要旨：**"这不是为了消除念头，而是改变你和念头的关系"**——与 ACT 的认知解离一致。

## 五、暴露阶梯

分级暴露（Graduated Exposure）：L1→L5 从舒适区边缘到挑战区，**不跳级**。关键原则写进 UI："完成暴露后什么都不做——不安慰、不中和、不找保证。焦虑出现是成功，不是失败。"

## 六、AI 引导（可选扩展）

参考 krishna 项目的状态机 + vignette 场景库结构：

- **系统提示词原则**：共情但不安慰式保证；命名 OCD 循环；每次给一个小的 ERP 实验；一次只问一个问题；绝不诊断、绝不鼓励仪式
- **主题匹配**：检查/污染/侵入性念头/关系，对应不同微实验建议
- **危机检测**：自伤关键词触发求助信息（热线 12356 等）

技术：OpenAI 兼容接口（fetch），密钥本地存储，无后端。设计为**可选**——不配置不影响任何核心功能。

## 七、技术选型

| 决策 | 选择 | 理由 |
|---|---|---|
| 形态 | PWA 单文件 | 手机/PC 通用、可安装、离线、无需商店审核、无构建 |
| 存储 | localStorage | 零配置、数据本地、够用（记录 ≤500 条） |
| 语音 | Web Speech API (TTS) | 系统自带中文语音，离线可用 |
| 震动 | Vibration API | Android 支持，增强中断 |
| 图表 | 手绘 canvas | 避免 CDN 依赖（离线优先） |
| 版本 | 语义化版本 | v0.1 起 |

## 八、已知限制与规划

- **限制**：localStorage 容量有限（~5MB）；iOS Safari 无震动/无全屏 API；TTS 音质取决于系统引擎
- **v1.0 规划**：自定义语音录制、紧急联系人一键通知、触发模式周报、数据导出、腾讯云部署

## 九、安全边界

- 工具不诊断、不保证、不替代治疗
- 记录功能刻意保持"可选 + 30 秒内"——**防止记录本身成为新的强迫**
- 危机场景引导求助专业资源
