# 使用指南

## 一、安装与启动

### 电脑（Windows）
1. 双击 `scripts/start.bat`，自动启动本地服务器并打开浏览器
2. 或手动：`python -m http.server 8123` 后访问 `http://127.0.0.1:8123`
3. 建议用 Chrome/Edge 打开，地址栏右侧"安装"图标可把应用装到桌面，像普通软件一样使用

### 手机（同一 WiFi）
1. 电脑上运行 `ipconfig` 查看局域网 IP（如 `192.168.1.100`）
2. 手机浏览器访问 `http://192.168.1.100:8123`
3. Android Chrome / 桌面版 Edge：菜单 → **添加到主屏幕**
   iPhone Safari：分享按钮 → **添加到主屏幕**
4. 之后从主屏幕图标打开：全屏、无地址栏、支持震动

> 💡 首次访问后 Service Worker 会把全部文件缓存到设备，**之后断网也能用**。

## 二、发作时怎么用

1. **点主页大按钮「现在就需要帮助」**——会全屏接管 + 震动
2. 跟着引导做：中断（8 秒）→ 呼吸（6 轮）→ 着陆（5-4-3-2-1）→ 寄存
3. 寄存阶段可选：
   - 把念头写进**停车场**（不写也完全可以）
   - 预约**担忧时间**：到点才能想，现在先放着
   - 展开**冲动观察**：如果冲动强烈，做 3 分钟观察练习
4. 完成后填写记录（焦虑峰值 SUDS、情境、备注），**可选**，30 秒内完成
5. **30 分钟后**主页会出现"焦虑回访"卡片——回来再评一次分，看看焦虑降了多少

> 整个流程**随时可以退出**，工具绝不成为压力源。跳过任何一步都是允许的。

## 三、日常预防

### 每日 5 分钟微训练
- 主页 → 每日练习 → 开始
- 5 个 60 秒阶段：安顿 → 念头贴标签 → 允许焦虑 → 观察冲动 → 夺回主权
- 建议固定时间（如睡前/晨起）每天一次，形成习惯
- 连续天数会记录，别给自己压力——断一天不是失败

### 暴露阶梯
- 主页 → 暴露阶梯
- 从 L1 开始逐级挑战，**不跳级**
- 完成暴露后**什么都不做**：不安慰、不中和、不找保证
- 状态平稳时做（不是发作中）；每周 3-5 次，每周一次略高挑战

## 四、历史与自我观察

- 历史页：7 天趋势图（发作次数、平均 SUDS）+ 完整记录列表
- 每条记录含：时间、SUDS、触发标签、念头、备注、焦虑证据对比
- 数据只在本机，可清空

## 五、AI 引导（可选）

### 配置
设置 → AI 引导：
1. 接口地址：默认 `https://worldcodes.online/v1`（OpenAI 兼容）
2. API Key：在接口服务商处获取
3. 模型名：如 `claude-sonnet-4-6`

### 使用
- 主页出现「💬 和我聊聊」入口
- 可点主题快捷按钮（检查/污染/侵入性念头/关系）或自由输入
- AI 会：命名你的循环 → 给一个小的 ERP 实验 → 问一个问题
- 内置危机检测：提到自伤内容会显示求助信息

> ⚠️ AI 对话是辅助，不是治疗师。密钥只存本机浏览器。

## 六、设置项说明

| 设置 | 说明 |
|---|---|
| 语音引导 | 中文 TTS 念出指令；手机系统语音引擎差异较大，建议实测 |
| 震动提醒 | 中断阶段震动（Android 生效，iOS Safari 不支持） |
| 语音语速 | 慢/正常/快 |
| 解离短语 | 寄存阶段念的句子，可替换成你自己的话 |
| 默认担忧时间 | 念头停车场预约的默认时段 |
| AI 引导 | 接口地址/密钥/模型 |

## 七、常见问题

**Q：手机语音没声音？**
A：检查系统 TTS 引擎（安卓：设置→无障碍→文字转语音；确保装了中文语音包）。语音失败不影响动画引导。

**Q：想换电脑/手机迁移数据？**
A：数据在 localStorage 里，目前不支持导出。可在"历史→清空"后重新开始。（导出功能在规划中）

**Q：可以部署到公网吗？**
A：可以，把 `app/` 目录放到任意静态托管（需 HTTPS 才能安装到主屏幕），如腾讯云 COS、GitHub Pages 等。
